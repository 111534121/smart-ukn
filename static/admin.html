💡 帳號與密碼防呆說明：
  • 系統密碼採不可逆單向雜湊加密（Werkzeug Security Scrypt / PBKDF2）存檔，維護師生隱私安全。
  • 新進在校師生預設密碼為 123456；系統管理員預設密碼為 admin123。
  • 若師生忘記密碼，管理員可點擊「重設為預設密碼」即時還原；自訂新密碼長度須為 8～100 字元。
