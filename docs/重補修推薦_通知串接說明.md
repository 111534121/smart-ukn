# 重補修推薦：通知串接說明

給負責通知中心的呂泑禎。重補修推薦已經算好「每位學生哪些科目需要通知、通知要寫什麼、點了要開到哪裡」，通知中心只要取資料、顯示、處理已讀。

## 取得通知資料

### 方法一：在後端直接呼叫 (建議)

```python
import retake

notes = retake.notifications_for("S112001")   # 傳入學號，回傳 list；查無學生回傳 []
```

需要對多位學生發通知時 (例如每學期開課資料更新後)，對每個學號呼叫一次即可。

### 方法二：API

`GET /api/student/retake-recommendations` (學生本人或家長登入；學號一律取自 session)

回應中的 `notifications` 欄位就是同一份資料；`data` 是完整的推薦結果 (畫面用)。

## 每則通知的欄位

```json
{
  "student_id": "S112001",
  "type": "retake",
  "key": "retake:S112001:CS102:available",
  "course_id": "CS102",
  "course_name": "程式設計(一)",
  "status": "available",
  "title": "重補修：程式設計(一) 有班別可選",
  "body": "有 1 個班別不會跟你的課衝堂，推薦 資管五孝 (週四 第 2-4 節)。",
  "link": "/?retake=CS102#retake"
}
```

| 欄位 | 用途 |
|---|---|
| `key` | **去重用**。同一學生、同一科、同一狀態只通知一次；狀態改變 (例如原本全部衝堂、後來有班別可選) 時 key 會不同，可以再通知一次 |
| `status` | `available` 有班別可選、`all_conflict` 全部衝堂、`not_offered` 本學期未開課。已經在課表的科目不會產生通知 |
| `title` / `body` | 直接顯示，不用再組字 |
| `link` | 點通知後開啟的網址 |

## 點進通知後

`link` 會開到首頁的「重補修推薦」分頁 (`#retake`)，`?retake=課程代碼` 讓畫面自動捲到那門課並標示 3 秒 (`static/js/retake.js` 的 `rtFocusFromLink()`)。

測試方式：用 student1 / 123456 登入後開 `http://127.0.0.1:8000/?retake=CS102#retake`，應該會看到「程式設計(一)」那張卡片被框起來。
