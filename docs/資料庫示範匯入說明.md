# 41 張資料表的去識別化示範資料庫

檔案：`smart_ukn_demo_41_tables.sql`

這份 SQL 由 2026-10-22 的 41 張表匯出檔產生，保留資料表、索引、外鍵及原有資料列數（共 2,026 列；其中 38 張表有資料）。學生 ID、姓名、帳號、電話、電子郵件、自由文字、JSON 內容與檔案路徑已替換為示範值。帳號密碼雜湊和外部服務 token 已改為不可登入的佔位值。

## 匯入

1. 在 MySQL/MariaDB 建立一個**新的空白** `smart_ukn` 資料庫，字元集使用 `utf8mb4`。
2. 使用 phpMyAdmin 的「匯入」功能選擇 `smart_ukn_demo_41_tables.sql`。
3. 匯入後可檢查是否有 41 張表。示範帳號不能直接登入；需要測試登入時，請在本機使用專案的示範資料建立工具另行建立帳號。

請勿將這份檔案匯入既有的正式資料庫，因為它含有 `CREATE TABLE` 與示範資料列。原始含個人資料的 SQL 匯出檔不在 GitHub 中。

如需重新產生，請在本機執行 `python tools/anonymize_sql_dump.py <私人匯出檔.sql> smart_ukn_demo_41_tables.sql`，並先檢查新檔再提交。
