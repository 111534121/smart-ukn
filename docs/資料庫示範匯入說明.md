# smart_ukn.sql 資料庫匯入說明

檔案：`smart_ukn.sql`（全系統唯一正式資料庫檔案，共 62 張資料表、43 條外鍵約束）。

## 匯入步驟

1. 在 MySQL / MariaDB（或 XAMPP phpMyAdmin）建立一個**新的空白** `smart_ukn` 資料庫，字元集選擇 `utf8mb4_unicode_ci`。
2. 使用 phpMyAdmin 的「匯入」功能，或執行以下指令匯入：
   ```bash
   mysql -u root smart_ukn < smart_ukn.sql
   ```
3. 匯入完成後可確認共有 **62 張資料表**（包含臨時停課／調課 `course_changes`、線上會議 `meetings`、真實康寧師資 `teacher_directory` 與 `faculty_profiles` 等完整結構與資料），且在 MySQL 嚴格模式（`STRICT_TRANS_TABLES`）下為 **0 錯誤、0 警告**。

> 注意：請勿將本檔直接匯入已有資料的資料庫（內含 `CREATE TABLE` 與初始資料）；若需備份請先執行 `mysqldump`。
