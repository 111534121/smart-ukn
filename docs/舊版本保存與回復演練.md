## 實際需要回復時

1. 先另備份當下的程式、MySQL、campus_store.json 與私有附件；避免用舊資料蓋掉新進度。
2. 使用新目錄／獨立資料庫演練。可執行本工具重建驗證證據，原始備份保持不變。
3. 只要取回程式時，在新目錄解壓指定版本 ZIP，或由 bundle 建立獨立 clone 後檢出指定 commit；不要直接在現行資料夾執行 reset --hard。
4. 如需還原資料，由資料管理者核對時間點與目標庫後停止服務，還原同批 SQL／JSON／私有附件。程式版本與 schema 必須一起核對。
5. 回復後驗證登入、老師只能查看授權班級、請假來源、通知收件者與回條、宿舍審核權限、學生／家長結果同步，再開放服務。
6. 記錄操作人、備份時間、還原 commit、目標資料庫、驗證結果及尚待補回的新資料。

MySQL DDL 不能靠 transaction rollback 保證回復；原始上傳附件未包含於此 SQL 備份，必須另行備份附件目錄。恢復全部歷史業務狀態仍依當時是否有對應資料備份而定，不以 Git 程式版本冒充資料備份。
