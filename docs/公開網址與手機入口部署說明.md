# 校園智慧官網：固定網址與手機入口

本專題採用「響應式網站＋可加入主畫面的 PWA」。專題名稱仍為「校園智慧官網」，不需要另外開發或上架原生 App。QR Code、LINE 分享及主畫面捷徑都回到同一個網站。

## 已準備的功能

- 首頁的「把校園智慧官網帶著走」提供 QR Code、下載 SVG、複製公開首頁網址、LINE 分享、加入主畫面。
- QR Code 在本站產生，不使用第三方 QR 圖片服務。
- 僅分享固定公開首頁，不帶登入憑證、帳號、搜尋文字或個人頁面的網址。
- 尚未設定公開網址時，QR Code／分享／複製按鈕停用，並清楚顯示預覽狀態。
- 支援安裝提示的瀏覽器會出現加入主畫面提示；iPhone、LINE 內建瀏覽器等情況提供操作說明。

## Render 部署準備

專案根目錄已新增 `render.yaml`，採用 Flask＋Gunicorn、一個程序與四個執行緒，避免記憶體示範資料被拆到多個程序。正式入口為 `wsgi:app`，健康檢查為 `/healthz`。設定關閉自動部署，避免每次推送程式就直接更動公開網站。

此設定使用 **付費 starter 主機及 1 GB 持久磁碟**，並非免費方案。建立服務前請在 Render 確認當下費用；這份設定本身不會建立資源或扣款。

1. 先將這次要上線的程式整理到 GitHub；目前工作目錄包含其他尚未提交的工作，不應直接把整個工作目錄推送或打包上傳。
2. 在 Render 登入後選擇 New → Blueprint，連接 `111534121/smart-ukn` 儲存庫，選擇 `deploy/public-campus-20261021` 部署分支。`render.yaml` 位於該儲存庫根目錄。
3. 確認主機名稱、區域及費用後建立服務。服務名稱的可用性由 Render 決定，不能事先保證一定取得 `smart-ukn.onrender.com`。
4. 上線完成後，Render 提供固定的 HTTPS 網址。程式會自動讀取 `RENDER_EXTERNAL_URL`，QR Code 與 LINE 分享即使用這個網址。
5. 若使用自訂網域，先完成主機的網域／HTTPS 設定，再設 `PUBLIC_SITE_URL=https://實際網域/` 並重新部署。只接受 HTTPS 根網址，不接受 localhost、區域網路位址、查詢參數或個人頁面路徑。
6. 用手機行動網路開啟公開網址，掃 QR Code、分享至 LINE，並在 iPhone Safari／Android Chrome 實測加入主畫面。

## 資料保存與示範範圍

`PERSISTENT_ROOT=/var/data`：

- `campus/`：校園功能的 JSON 儲存。
- `uploads/`：上傳附件，包含文件庫下載使用的相同目錄。
- `forms/`：產生的表單。
- `links.json` 與 `school_calendar.json`：第一次啟動從版本庫的公開設定複製，之後不覆蓋磁碟上的更新。

部署不會複製本機的 `my_data.json`、`data/` 或學生上傳文件。資料庫未設定時沿用既有示範模式，**部分記憶體中的操作仍會在重啟後重設**；持久磁碟不等於整個系統都已接上正式資料庫。此部署配置適用於專題示範，不能直接視為正式校務系統。

若需完整資料保存，另行提供 MySQL 的 `DB_HOST`、`DB_PORT`、`DB_USER`、`DB_PASSWORD`、`DB_NAME` 並依專案資料庫流程初始化。Render 的 PostgreSQL 不能直接替換目前 MySQL 連線。

`SECRET_KEY` 在主機上自動產生；HTTPS 部署啟用 `SESSION_COOKIE_SECURE=1`。本機 HTTP 預覽維持 0。不要把本機環境檔或金鑰提交到版本庫。

## LINE 範圍

這次完成的是 LINE 的「分享網站」入口，使用者自行選擇分享對象及送出。沒有自動寄送訊息、沒有 LINE Login、沒有綁定學號，也沒有推播。

未來如有 LINE 官方帳號，可將圖文選單連至公開首頁或 `/#calendar`、`/#map`。帳號綁定、個人通知、LIFF 是下一階段功能，不影響官網主體。
