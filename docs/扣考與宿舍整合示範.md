# 扣考預警與宿舍審核整合示範

更新：2026-10-21。保留另一個聊天新增的行政案件／處室工作台，未還原其修改。

## 老師端

1. 開啟 http://127.0.0.1:8000/ ，用 `teacher1`／`123456` 登入。
2. 進入「班級出缺勤」，查看學生 S112001 的四門【示範】課程：17 小時是門檻前、18 小時達門檻、19 小時超過；普通病假 18 小時也計入。這四門課的學期總時數均為假設的 54 小時，不能套用至真實課程。
3. 點學生資料查看待審／已核准的【模擬串接】假單。核准假單不會直接抹除缺席紀錄，須由課程與節次對應後再確認。
4. 可從預警名單使用一鍵提醒，並在班級通知查看廣播、已讀與回條。提醒範圍只包含所選學生。

校規依據：康寧大學教務處公告的[專科部學則（2026-04-20）](https://daa.ukn.edu.tw/p/406-1021-42550,r11.php?Lang=zh-tw)第 17 條，以及[大學學則（2026-04-21）](https://daa.ukn.edu.tw/p/406-1021-42562,r11.php?Lang=zh-tw)第 11 條。

一般缺曠達全學期授課時數三分之一；公假、重大傷病假及孕產育兒等例外需依核定分類處理。系統對未確認的例外標示人工確認，舊資料缺少實際時數或課程總時數時標示估算。「達門檻」是預警，正式扣考仍須校方確認；提前提醒比例是系統設定，並非校規條文。

## 宿舍管理端

1. 開啟 http://localhost:8000/ ，用 `dorm_demo`／`123456` 登入；此帳號具宿舍管理權限。
2. 進入「宿舍申請」，查看學期「示範115-1」兩筆虛構申請：S112001 已分配床位 `DEMO-S305-2`；S112002 顯示未通過及原因。
3. 進行中的申請可依序推進資格審查、床位排序、床位分配、繳費、完成入住；分配階段需填床位，未通過需填原因。結案後不可重複推進，並保留每次操作者與處理時間。
4. 另以 `student1`／`123456` 或 `parent1`／`123456` 登入，查看同一筆申請的進度、床位和審核歷程。一般 `staff1`、老師、學生、家長都不能呼叫宿舍管理／審核 API。
