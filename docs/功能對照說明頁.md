# 功能對照說明頁

啟動原本的校園服務系統後，點選首頁右上方「功能對照說明」，或開啟 `/feature-guide.html`。

此頁可搜尋功能名稱、API、程式檔或資料表，依分類篩選，展開端點查看後端入口、SQL 引用、建表位置、JSON 儲存來源與追蹤到的函式，也可列印目前選取的功能。網址的 `#功能代碼` 可用來分享特定功能。

頁面只載入產生好的結構資訊，不會呼叫業務 API、顯示程式全文或讀取資料庫內容。原有功能與權限不受影響。本次為既有專案新增本機頁面，未另外部署網站。

程式修改後，在專案目錄執行：

```powershell
python build_feature_guide.py
```

將更新後的 `static/feature-guide-data.js` 與網頁一同部署。產生器只讀取指定的程式碼及建表檔，不讀取 `.env` 或執行時資料。功能的中文摘要與 API 分組定義在產生器的 `FEATURES`；新增 API 若尚未分組，會自動出現在「其他校園服務端點」。

資料表對照屬靜態分析，涵蓋 SQL 字串、同檔函式、明確匯入函式及 `deps` 呼叫。動態 SQL、物件方法及部分跨模組呼叫可能未涵蓋；未偵測到表名不表示沒有間接存取資料庫。共用函式可能帶入驗證或稽核使用的表。JSON、記憶體或外部服務是否使用，仍依實際執行設定決定。

驗證：`python -m pytest tests/test_feature_guide.py`。
