# 老師今日工作台、關懷追蹤與通知回條

## 使用入口

以老師帳號登入後，首頁即顯示「老師今日工作台」。既有示範帳號為 `teacher1`，密碼 `123456`。

- 工作台：今日課表、待審假單、證照、學業預警、追蹤到期、待收回條、導師班摘要。關懷待辦依日期排序，可直接開啟原紀錄處理。返回首頁或按重新整理會更新，頁面可見時每 90 秒更新。
- 我的導師班 → 關懷紀錄：新增追蹤日期、待聯繫／已聯繫／追蹤中／已結案、處理結果。可篩選待追蹤或今日到期與逾期，結案後移除到期提醒，修改階段可重新開啟追蹤；下載表格亦包含新增欄位。
- 班級通知：班級通知與課程廣播均可勾選「需要學生回條」，期限沿用通知日期，空白代表不設期限。
- 學生端 → 班級通知：展開通知後，選擇收到／會參加／無法參加／需要協助。截止前可更新回條，每人只計一次；送回條同時標記已讀，單純已讀不計為已回覆。
- 老師端 → 班級通知 → 已發送：分開顯示已讀與已回覆、回覆內容與時間、未回覆名單。「只提醒未回覆學生」產生站內提醒，不寄信或發送外部訊息；學生回到原通知填回條。

## 權限與資料

老師僅能查看導師班關懷紀錄，只有紀錄作者及管理員可修改；學生、家長無權查看關懷內容。老師的已發送與回條僅限本人發出的通知，管理員可管理全校。學生只能回覆自己的通知，家長僅能檢視子女回條，不能代填。期限當日仍可填寫，次日拒絕回覆及提醒。

## 資料庫升級

示範模式沿用 `data/campus_store.json`，不必建表。新增資料皆持久保存，舊通知預設不需回條，舊關懷紀錄依完成旗標推導處理階段。

**使用既有 MySQL 的環境，先停止舊服務，在專案目錄執行 `python teacher_workbench_schema.py`，完成後重啟服務。** 此增量升級僅新增六個欄位，可以重複執行，不刪除紀錄、不重設帳號、不匯入示範資料。MySQL DDL 會自動提交；若中斷，修復問題後重跑即可。新安裝執行既有 `init_db.py` 也會補齊欄位；`smart_ukn.sql` 已同步新欄位定義。

此變更尚未對實際 MySQL 執行升級，也未部署到正式環境。MySQL 存取路徑以替身測試檢核，仍需在目標資料庫升級後驗收。
